# Паспорт мини-проекта (ПР №6)

| Поле | Содержание |
|---|---|
| **Название** | MVP «B2B-маркетплейс закупок с банковской оплатой» |
| **Цель** | Объединить тему 1 «Банки и финтех» (модуль А) и тему 10 «Розничная торговля» (модуль Б) в один работающий процесс: заказ ритейлера у поставщика оплачивается банковским платёжным поручением, итоговый статус фиксируется в блокчейне |
| **Участники и вклад** | **Айкенов Ерасыл** — модуль А (PaymentOrderRegistry), банковский адаптер, вкладка «Расчёты», правила R-1/R-2, сверка платежа в хабе. **[ФИО сокомандника]** — модуль Б (PurchaseOrder), адаптер ритейла, каталог/корзина/заказы. **Совместно** — DATA_CONTRACT, хаб, оркестратор, R-3, приёмка (см. CONTRIBUTIONS.md) |
| **Сценарий** | Ритейлер создаёт PurchaseOrder (Б) → поставщик подтверждает (Б) → оркестратор **автоматически** регистрирует платёж с суммой и хешем из Б (А) и связывает в хабе → расчётный центр исполняет платёж (А) → оркестратор вызывает `hub.finalize` → `Paid` |
| **Вход** | Выбор товаров поставщика из каталога и количества |
| **Выход** | Итоговый статус заказа `Paid` / `PaymentFailed` + цепочка txHash всех шагов |
| **Результат для пользователя** | Ритейлер видит «оплачено», поставщик — «оплата получена, можно отгружать», аудитор — сквозную историю по одному `orderId` |
| **Модули** | Б: `RetailPurchaseOrder` — коммерческая часть (PO, закупочная стоимость, подтверждение). А: `PaymentOrderRegistry` — платёжная часть (поручение, исполнение «4 глаза»). Hub: `OrderSettlementHub` — связь и итоговый статус по данным обоих модулей |
| **Общий идентификатор** | `orderId = keccak256(utf8("PO-2026-NNNNNN"))`; `paymentId = keccak256(abi.encode(orderId, attempt))` |
| **Источник истины** | Только блокчейн: статус PO — в Б, статус платежа — в А, итоговый — в хабе. Файлы оркестратора — кеш |
| **Критерии приёмки** | К1 нет ручного обмена (≤ 10 с), К2 согласованность (0 расхождений), К3 защита общей операции, К4 восстановление ≤ 60 с — см. ACCEPTANCE_CRITERIA.md |
| **Стек** | Solidity 0.8.28, OpenZeppelin 5.6.1, Hardhat 3 + viem 2, Node 24, React 18 + Vite 5, node:test |
| **Запуск** | `1_START_DEMO.cmd` (или `npm run demo:up`) → http://localhost:5173; результаты — `2_SHOW_RESULTS.cmd` |
